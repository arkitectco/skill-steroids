# Post-Session SkillSteroids Reminder

Optional. Copy into project `AGENTS.md` or a Cursor user rule.

## Snippet

After completing a multi-step task (3+ tool calls or 1+ file writes), append to your mental checklist:

> If skill friction occurred (wrong skill loaded, repeated explanations, manual overrides), run **"skill steroids audit"** and paste 1–3 friction bullets.

## Session bootstrap (plugin install)

Plugin installs inject the friction nudge via `using-skill-steroids` SessionStart hook. Symlink users can paste the snippet above into a user rule.

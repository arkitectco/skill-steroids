# SkillSteroids Skill Pack

Skill content for the SkillSteroids plugin. Lives at `plugin/skills/skill-steroids/` in this repo.

Marketplace install uses `./plugin` (`grok plugin install arkitectco/SkillBotox#plugin --trust`). Symlink fallback: repo-root `./install.sh` links this directory to `~/.cursor/skills/skill-steroids`.

Do not install this directory manually from the monorepo root — use marketplace install or `./install.sh`.
